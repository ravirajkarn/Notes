# Tuple
## What is a tuple in Python?
A **Tuple in Python** is represented as a list of values separated with commas enclosed within parentheses ( round brackets). It can store values of any data type.

**_For example_**, (“mango”, “apple”, “dragon fruit”, ” grapes “) is a tuple.

## Features of Python Tuple
1. The tuple is an immutable data type i.e, Tuples are not modifiable, hence we can not change the elements of the tuple, once created.
2. Tuples are ordered sequence which means that all the elements have a defined order, and that order will not change.
