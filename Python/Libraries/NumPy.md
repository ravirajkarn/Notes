# [NumPy](https://numpy.org/doc/stable/index.html)

It is simple array creator or manager just like array in cpp.

# various function
- [ ] `numpy.arange(start, end, steps)`: This create a array of number staring from `start` and ends in `end` different between each number is `steps`. Just like AP(Arithmetic Progression)
- [ ] `numpy.array(values)`: Create array of values.
- [ ] `numpy.roots(Cofficients)`: Solve for roots. It take input as array of Coefficients and solve it.
