# Sympy
It a symbolic representation of mathematical expression.

## various function 

> [!important]
>`sympy.symbols(string)`: It create symbolic or say variables in expression.

- `sympy.solve(expression, sympy.symbols(string))`: It solve for the roots in the `expression` provided and the variables in `sympy.symboles(string)`.
