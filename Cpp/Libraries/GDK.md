# GDK
GDK(GDK GTK Drawing Kit) is the low-level abstraction layer beneath it, handling platform-specific details like window management, input and rendering for various operating systems(X11, Wayland, Windows, macOS)
## Cursor (class)
use to create and destroy cursors.
- Cursors are immutable object, so once you create them, there is no way to modify them later.
