# std::size_t 
## Int & size_t are both same.

## Difference 

| Int                                                              | Size_t                                                       |
| ---------------------------------------------------------------- | ------------------------------------------------------------ |
| Represent both signed and unsigned i.e + and - value by default. | It represent only unsigned number by  default.               |
| Based on 32 bits                                                 | System dependent it could be 32 or 64 bits.                  |
| General integer arithmetic.                                      | For memory - related operations, representing sizes, counts. |
|                                                                  | Size_t defined in \#include \<csteddef\>                     |
|                                                                  | Std::size_t                                                  |
