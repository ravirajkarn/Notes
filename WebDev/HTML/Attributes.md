## Style and layout Attributes

> [!example] style
> Sets the style of the elements using a variety of properties and values. Which properties can be set to is determined by the element to which the style attribute is applied. 

> [!example] id
> Sets the reference of an id style is a stylesheet. id styles are used by single element. 

> [!example] class
> Sets the reference of a class style in a stylesheet. Class styles can be used by one or more elements.

> [!example] display
> Sets how the elements should be presented relative to other elements. For example, "display: inline" will force the element and nearby elements to be presented next to each other horizontally. 

> [!example] aria-lablel
> Sets a name or label to #HTML elements for assistive technology(for example, screen readers).

## Action attributes

> [!example] href
> Sets the destination of a linked resource like a hyperlink.

> [!example] src
> Sets the location of a resource like a media file that should be brought into the web page.

> [!example] Autofocus
> Instructs the browser that the elements should get the focus when the page loads.

> [!example] Draggable
> Indicates whether the element is draggable or not.

## Event Attributes

> [!example] onclick
> Sets the script function to run when the user clicks the element.

> [!example] onerror
> Sets the script function to run when an error occurs .

> [!example] onkeypress
> Sets the script function to run with the user pressing a key.

> [!example] onscroll
> Sets the script function to run when the user scrolls the page.
