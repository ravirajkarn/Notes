# JS Introduction 
JavaScript is likely behind the interaction when you click a button or use a drop-down menu on the web. Browsers implement an interpreter that reads JavaScript and performs actions based on the script. Like CSS, developers can place JavaScript directly in an HTML document or a separate file so all web pages can use it.

Developers often use JavaScript code to respond to an **event**. An event is something that happens on a web page. Here’s how it works!
- You initiate an event when you click a button or drag a photo on a web page. HTML elements, such as a button element, have **event listeners**. Event listeners receive instructions from an interaction on a web page.
- When they get those instructions, then they can carry-out the specific tasks. In programming languages, these tasks are called **event handlers**. Event handlers on the web are writing in JavaScript.![[event-animation.gif]]
