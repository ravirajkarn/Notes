# Introduction React
React is WebDev Library based on JavaScript.


> [!important]
> You should very clear about naming convention.
> # 1. Components
> - **PascalCase**: React component functions **must start with a capital letter**.
># 2. Custom Hooks
>- **`use` Prefix**: Custom hooks **must start with the lowercase prefix `use`** followed by a capitalized letter in camelCase (e.g., `useAuth()`, `useLocalStorage()`). This rule is strictly enforced by React's compiler and developer tools to safely track hook execution behaviors.
># 3. Styling and Constants
>- **Global Constants**: Use **SCREAMING_SNAKE_CASE** (all uppercase letters separated by underscores) for static configuration constants that never change values (e.g., `const API_BASE_URL = "..."`).
>- **CSS Classes**: If you are writing raw CSS files, stick to **kebab-case** for styling selectors (e.g., `.submit-btn { ... }`).
