# Difference or Changes on git 
## 1. **`git status`:** 
Show a summary of which files is modified, added, deleted or un-tracked.
## 2. **`git diff`:** 
Show the line by line differences of un-staged changes.
- to see changes for a specific file, use `git diff <filename>`.
## 3. **`git diff HEAD`:** 
Show all changes, both staged and un-staged, between last commit.
