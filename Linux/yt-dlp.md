# yt-dlp
yt-dlp is a feature-rich command-line audio/video downloader with support for thousands of sites

```bash
yt-dlp -f "bestvideo[ext=mp4]+bestaudio[ext=m4a]/best[ext=mp4]/best" --merge-output-format mp4 "VIDEO_URL"
```
