# ls
list all the file in the given directory.

## Option	Function
-l	Uses a long listing format, showing details like size, date, permissions, etc. (required to see the information you're sorting by).
-t	Sorts by time (modification time by default).
-S	Sorts by size (largest first).
-r	Reverses the sort order (e.g., from newest-first to oldest-first, or largest-first to smallest-first).
-h	Displays file sizes in human-readable format (e.g., K, M, G).
