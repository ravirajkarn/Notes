# Kismet
Kismet is a network detector, packet sniffer, and intrusion detection system for 802.11 wireless LANs. Kismet will work with any wireless card which supports raw monitoring mode, and can sniff 802.11a, 802.11b, 802.11g, 802.11n, 802.11ac and 802.11ax traffic

Kismet is more than a scanning tool. Kismet is actually a framework for 802.11 packet capturing and analysis. In fact, the name Kismet is ambiguous. Kismet actually comes with two binaries: kismet_server and kismet_client; the executable kismet is merely a shell script to start them both in typical configurations.

## command
```bash
kismet
```
:Note: This will provide you a local link which will redirect you to it's web application.
