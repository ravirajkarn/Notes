# Type of Libraries
## Normal Libraries 
It is normal nothing special.
## Object Libraries
Object libraries may contain only sources that compile, header files, and other files that would not affect linking of a normal library (e.g. `.txt`).

## Interface Libraries
An interface library with no source files is not included as a target in the generated buildsystem.

## Imported Libraries
 A library file located outside the project
